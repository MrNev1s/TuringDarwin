## Prior source audit

The prior v0.2 source was read-only in intent and contained no direct MMIO/DMA
path, but it had these release blockers:

- no required `-tdprobe` gate;
- no `-tdoff` gate;
- `super::start()` ran before exact identity gating;
- no extended capability walk;
- shallow PM/MSI/MSI-X/PCIe decoding;
- moving `master` dependency in the SDK bootstrap script;
- no Xcode build or target-machine result attached.

Version 0.1 in this package addresses the source-design items. Compilation and
live behaviour remain unverified until the first target-machine run.


## v0.1 release result

The replacement source uses primary and secondary PCI matching, repeats the
exact identity gate before `super::start`, requires `-tdprobe`, rejects every
more-privileged mode, reads only PCI configuration and registry metadata, and
publishes finite arrays for capabilities and assigned memory descriptors.

No binary kext is included because this analysis environment is not macOS and
could not execute Xcode. See `RESULT-MATRIX.md` for the proof boundary.
